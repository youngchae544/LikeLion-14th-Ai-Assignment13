# MoodPick

이미지와 텍스트를 활용한 AI 콘텐츠 추천 앱입니다.

## 1. 앱 이름

**MoodPick**

## 2. 앱이 해결하려는 문제

볼 수 있는 영화나 드라마가 너무 많아 자신의 현재 기분이나 원하는 분위기에 맞는 콘텐츠를 선택하기 어려운 문제를 해결합니다.

## 3. 사용하는 데이터

이미지와 텍스트를 사용하는 멀티모달 앱입니다.

- **이미지**: 영화 포스터 또는 콘텐츠 이미지
- **텍스트**: 사용자가 입력한 현재 기분, 원하는 분위기, 선호하는 장르 등의 정보

AI가 이미지와 텍스트를 함께 분석하여 콘텐츠를 추천합니다.

## 4. AI가 하는 역할

AI가 콘텐츠 이미지에서 확인할 수 있는 분위기와 특징을 분석하고, 사용자가 입력한 텍스트를 함께 분석합니다.

이를 바탕으로 사용자의 현재 기분과 취향에 적합한 영화나 드라마를 추천하고 추천 이유를 설명합니다.

## 5. 사용자가 받을 수 있는 데이터

사용자는 다음과 같은 정보를 받을 수 있습니다.

- 추천 콘텐츠 제목
- 장르
- 콘텐츠의 분위기
- 추천 이유
- 비슷한 콘텐츠

## 6. 사용 예시

사용자가 영화 포스터 이미지를 업로드하고 다음과 같이 입력합니다.

> 오늘은 스트레스가 많아서 아무 생각 없이 웃을 수 있는 영화를 보고 싶어요.

AI는 이미지와 사용자의 입력을 함께 분석하여 현재 기분에 적합한 콘텐츠를 추천합니다.

### 예시 결과

**추천 콘텐츠:** ○○○

**장르:** 코미디

**분위기:** 밝고 유쾌함

**추천 이유:**  
사용자가 입력한 "스트레스를 풀고 웃을 수 있는 영화"라는 조건과 콘텐츠 이미지에서 확인되는 밝고 유쾌한 분위기를 종합하여 추천했습니다.
